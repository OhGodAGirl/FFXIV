# Glamour Shopper publication images

- `icon.png` is the approved public plugin icon.
- `icon-release-candidate.png` and its master remain review assets until the
  exact candidate is explicitly approved.
- `ui-preview.png`, `settings-preview.png`, and `completed-preview.png` are the
  sanitized README screenshots.

Before publication, inspect the exact icon at 512, 64, and 32 pixels, confirm
that the README screenshots match the live-tested candidate, and verify that no
character names, profile IDs, chat, or unrelated game overlays are visible.
