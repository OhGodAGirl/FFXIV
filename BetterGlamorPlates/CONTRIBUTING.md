# Contributing to Better Glamour Plates

Discuss a feature before implementation when its scope, safety, native access,
data behavior, or UI placement is not already settled.

## Changes

- Keep the change within Better Glamour Plates' documented product scope.
- Minimize unrelated formatting, renaming, and cleanup.
- Explain what changed, why it is needed, and why the approach is safe.
- Add or update tests for changed policy and confirmed regressions.
- Update player documentation when behavior, setup, privacy, or limitations change.
- Do not commit generated packages, staged plugins, personal data, or machine paths.

## AI assistance

Disclose AI assistance when required by the destination repository or
distribution policy. You remain responsible for reviewing and explaining every
generated line, addressing review feedback, and owning the validation evidence.

## Validation

Run the repository's locked restore, formatting, Release build, complete tests,
package inspection, and applicable live scenarios. A passing build is not proof
of in-game behavior.
