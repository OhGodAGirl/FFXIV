# Better Glamour Plates publication images

Do not create `icon.png` by renaming an unapproved candidate.

1. Produce `icon-candidate-master.png` and `icon-candidate.png` using the private icon authority.
2. Apply the canonical peel and run `Test-PluginIcon.ps1`.
3. Inspect the generated 512/64/32 review sheet beside sibling plugin icons.
4. Obtain explicit approval for the exact candidate.
5. Copy the approved candidate to `icon.png` and rerun plugin conformance.

Approved README screenshots use the exact live-tested candidate and contain no
unintended character names, IDs, chat, world, gil, or unrelated overlays.
