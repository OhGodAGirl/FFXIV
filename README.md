# FFXIV

FFXIV plugins, tools, and presets by OhGodAGirl.

## Projects

- [CollectionExporter](CollectionExporter) — creates FFXIV Collect import data
  from your character's collections.

- [Exportaramus](Exportaramus) — tracks collections and stored items, shares snapshots with compatible plugins, and exports to FFXIV Collect.

Each project includes its own setup instructions and license.
