# FFXIV

FFXIV plugins by OhGodAGirl.

## Projects

| Plugin | Description |
| --- | --- |
| [Better Glamour Plates](BetterGlamorPlates/README.md) | Browse your Glamour Dresser and Armoire, save outfits, preview dyes, and load outfits into Glamour Plates. |
| [Collection Shopper](CollectionShopper/README.md) | Find missing collectibles, compare price estimates, and buy from the Market Board within your chosen gil limits. |
| [Exportaramus](Exportaramus/README.md) | Track your collections and stored items, and export your progress to FFXIV Collect. Required for Better Glamour Plates, Collection Shopper, Spring Cleaning, and EZ Delivery. |
| [EZ Delivery](EZDelivery/README.md) | Speed up Grand Company Expert Deliveries and shop for missing Quartermaster items. |
| [Spring Cleaning](SpringCleaning/README.md) | Store eligible glamour items in the Dresser or Armoire and remove duplicate appearances. |

Each project's README covers its requirements, setup, and usage.
