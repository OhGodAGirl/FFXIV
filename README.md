# FFXIV

FFXIV plugins by OhGodAGirl.

## Projects

| Plugin | Description |
| --- | --- |
| [Better Glamour Plates](BetterGlamorPlates/README.md) | Browse your Glamour Dresser and Armoire, save outfits, preview dyes, and load outfits into Glamour Plates. |
| [Collection Shopper](CollectionShopper/README.md) | Find missing collectibles, compare price estimates, and buy from the Market Board within your chosen gil limits. |
| [Exportaramus](Exportaramus/README.md) | Track collections and stored items, share snapshots with compatible plugins, and export progress to FFXIV Collect. |
| [EZ Delivery](EZDelivery/README.md) | Speed up Grand Company Expert Deliveries and shop for missing Quartermaster items. |
| [Spring Cleaning](SpringCleaning/README.md) | Store eligible glamour items in the Dresser or Armoire and remove duplicate appearances. |

Exportaramus supplies collection and storage data to Better Glamour Plates,
Collection Shopper, Spring Cleaning, and EZ Delivery's missing-item shopping.
EZ Delivery's Expert Deliveries work without it.

Each project's README covers its requirements, setup, and usage. Source being
available here does not mean a downloadable release is available in the Plugin
Installer. See the individual project for release information and its license.
