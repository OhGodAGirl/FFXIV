# EZ Delivery 1.0.0.0 source preview

Fast(er) Expert Deliveries.

## Included

- Repeated Expert Deliveries using the selected in-game filter, with seal-cap checks that include bonuses.
- Quartermaster browsing for missing Weapons, Armor, Barding, and Furniture using Exportaramus snapshots.
- Buy One and Buy All, with explicit start and stop controls and transaction confirmation.
- Five tab styles, support for all eight FFXIV themes, and a prepared diagnostic report.

## Collection data

Exportaramus is required for missing-item shopping. Expert Delivery does not
require it. The pinned CollectionData 1.1 contract matches the compatibility
surface retained by Exportaramus 1.0.0.1.

Shopping may use a last complete saved snapshot. Refresh stored items in
Exportaramus when you need more recent information. Missing or incomplete source
data remains unknown. Furniture checks storage, not placed furnishings.
